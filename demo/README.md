# Синтетические кадры для демонстрации

`overview-demo.png` и `plate-demo.png` нарисованы программно, не изображают реальное событие и не предназначены для подачи обращения. Оба кадра имеют надпись «ДЕМО / СИНТЕТИКА». Пересоздать: `python demo/generate.py` (нужен Pillow).

В приложении загрузите эти файлы, укажите номер `А001АА 86`, обозначение «Дорожный знак или табличка», адрес «Демонстрационный адрес, не реальное событие», затем экспортируйте пакет. Для сброса удалите запись в «Истории». Этот набор проверяет интерфейс и архив, **не точность CV**.
