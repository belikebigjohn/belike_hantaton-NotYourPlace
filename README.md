# ЧужоеМесто

**Демонстрационный проект для Югорского хакатона.** ЧужоеМесто помогает собрать материалы о возможном занятии специального парковочного места: от двух фотографий до проекта обращения. Это инструмент подготовки материалов, а не система вынесения решений или автоматической подачи жалоб.

[Открыть тестовую версию](https://test.agentsofcremlin.netcraze.pro/) · [Демонстрационные фотографии](demo/README.md)

> Используйте для проверки только синтетические снимки и вымышленные данные. Доступность тестового сервера и интеграции MAX зависит от запущенного экземпляра на Mac Mini.

## Как проходит сценарий

1. Пользователь снимает общий план автомобиля и обозначения места, затем номер крупным планом. Камера показывает подсказки о качестве кадра и найденных объектах.
2. Приложение анализирует **оба** снимка: ищет номер и дорожные знаки, показывает кандидатов и рамки. Пользователь сверяет номер на каждом фото и исправляет ошибки распознавания.
3. Пользователь уточняет место, время и наблюдаемые обстоятельства, редактирует текст обращения.
4. Формируется ZIP с проектом обращения, исходными фотографиями и контрольными суммами. Архив можно скачать; при подтверждённом запуске через Mini App MAX предусмотрена отправка в чат бота. Ссылка `example.com` на последнем экране служит только для демонстрации — обращение никуда не подаётся.

## Что реализовано

| Часть | Реализация |
| --- | --- |
| Интерфейс | Адаптивное веб-приложение: мобильная камера почти на весь экран, история черновиков, настройки отображения |
| Анализ фото | OpenCV для проверки качества; YOLO-v9-t для поиска номера; Nomeroff Net для OCR российских номеров |
| Обозначение места | Модель дорожных знаков на 146 классов; проверка пары знаков 6.4 и 8.17 на общем снимке |
| Проверка человеком | Сравнение номеров на двух снимках, выбор кандидатов, ручное исправление и обязательное подтверждение |
| Пакет | DOCX, TXT, HTML, исходные снимки и manifest с SHA-256 в ZIP |
| Хранение | SQLite и оригиналы фотографий на сервере; материалы доступны в пределах сессии |
| MAX | Код проверки подписанных данных Mini App, приветствие бота с кнопкой открытия и отправка ZIP через Bot API |

Стек: React, TypeScript, Vite, FastAPI, Python, SQLite, OpenCV, ONNX Runtime, PyTorch и Ultralytics. [Подробности о моделях и их происхождении](docs/CV.md) · [Состав документов](docs/LEGAL_AND_DOCUMENTS.md).

## Запуск из исходников

Нужны Node.js 22, Python 3.12 и интернет при первой загрузке весов. На macOS также нужен совместимый с версией системы набор зависимостей из `backend/requirements.txt`. Веса моделей и пользовательские данные в репозиторий не включены.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
npm --prefix frontend ci
.venv/bin/python models/setup_models.py
npm run build
npm start
```

Откройте `http://127.0.0.1:8000`. Для Windows используйте `py -3.12 -m venv .venv` и `.venv\Scripts\python.exe` вместо `.venv/bin/python`. Для разработки: `npm run dev`.

Настройки приложения задаются в локальном файле `.env` по образцу [.env.example](.env.example). Без токена MAX основной браузерный сценарий работает отдельно. Инструкции для оператора тестового сервера и бота вынесены в [запуск на Mac Mini](docs/MAC_TEST_SERVER.md) и [настройку MAX](docs/MAX_SETUP.md).

## Проверка и ограничения

```sh
npm run check
npm run lint
npm test
npm run build
.venv/bin/python -m pytest tests/backend tests/test_documents.py -q
```

На Mac Mini ранее подтверждалась загрузка моделей и работа локального API. Последняя интеграция с MAX, физическая камера телефона и весь сценарий через внешний адрес требуют отдельной проверки на запущенном сервере; код в репозитории сам по себе не подтверждает их работоспособность.

Распознавание не доказывает нарушение. Для разметки на асфальте и знака инвалидности на автомобиле подтверждённых моделей пока нет; эти признаки остаются для проверки человеком. Независимая оценка точности на уличной выборке не проведена. Перед использованием с реальными персональными данными необходимы проверка безопасности, сроков хранения и условий лицензирования моделей.
