# Яндекс Карта места наблюдения

Карта добавлена на шаг «Место и время». Внешний сервис загружается после нажатия «Открыть Яндекс Карту» с пояснением о передаче координат. Фото, номер автомобиля и данные заявителя не передаются в параметры карты.

## Режим без ключа, согласованный с пользователем

Встроенный виджет Яндекс Карт показывает выбранные координаты маркером. Координаты устройства, полученные через существующую кнопку, также отображаются на карте. Неизвестное местоположение не подменяется центром города: без выбранных координат виджет открывается на общем виде Екатеринбурга без присвоения точки обращению. Доступны переход в Яндекс Карты и ручное уточнение широты/долготы с валидацией. Адрес остаётся редактируемым. Виджет не возвращает в приложение точку, выбранную внутри него; автоматическое извлечение её из iframe не имитируется.

Браузерная проверка выполнена при 390×844: реальный виджет загрузился, задана публичная тестовая точка 56.8389, 60.6057, маркер и координаты появились; горизонтального переполнения нет. Скриншот docs/screenshots/yandex-map-mobile.jpg содержит только карту публичного центра города. GPS физического телефона не проверен.

## Полноценный выбор точки и поиск адреса

Подготовлена интеграция JavaScript API 2.1: клик по карте, перетаскивание метки, обратное геокодирование, поиск введённого адреса. Для включения нужен ключ Яндекса:

```dotenv
YANDEX_MAPS_API_KEY=ваш_ключ_JavaScript_API
```

Затем перезапустите сервер и перезагрузите страницу. `/api/map-config` возвращает только этот публичный браузерный ключ. Ограничьте разрешённые HTTP Referer в кабинете Яндекса (локальные адреса для разработки и домен приложения для публикации). Серверные секреты в ответ не включаются. Скрипт SDK загружается только после открытия карты. Ответ устаревшего запроса геокодирования игнорируется, если человек изменил адрес/точку или ушёл с экрана.

[Официальный быстрый старт Яндекса](https://yandex.ru/dev/jsapi-v2-1/doc/ru/), [подключение API](https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/dg/concepts/load).

В этой среде ключа нет. SDK-интеграция проверена типизацией, сборкой и проверкой преобразования координат; живые клики/drag и геокодирование с ключом не проверены. Это ограничение явно отличено от работающего виджета без ключа. Поиск адреса через Nominatim (OpenStreetMap) работает отдельным действием и с отдельным согласием, без ключа Яндекса.
