# Проверка AUTO.RIA RU OCR

Источник: [архив пользователя](https://nomeroff.net.ua/datasets/autoriaNumberplateOcrRu-2021-09-01.zip), [Nomeroff Net](https://github.com/ria-com/nomeroff-net). Это размеченные изображения для OCR, а не файл готовых весов. Используется опубликованная русская ShuffleNet-модель Nomeroff; её конфигурация указывает тот же датасет. Переобучение не выполнялось.

В архиве 114251 запись ZIP, общий размер около 1,5 ГБ. Скрипт получает центральный каталог и выбранные элементы через HTTPS Range; весь архив не скачивается. Выбраны 60 случайных изображений из явного `test/ann` с seed 20261122. Фото и аннотации сохраняются только в игнорируемой `models/datasets/ru-evaluation`; в Git отправляется агрегированный отчёт без фотографий и госномеров.

| Путь обработки | Точно прочитано на этой выборке |
|---|---:|
| OCR исходного изображения номера | 60/60 |
| Детектор → обрезка → OCR, без нового fallback | 49/60 |
| Исправленный путь крупного плана | 60/60 |

Потери происходили при повторном поиске уже обрезанного номера. Для выделенного входа крупного плана добавлено чтение всего изображения, если обычный поиск не дал корректного полного номера и пропорции изображения похожи на однострочную табличку (2,5–6,5; высота от 20 px). Общий план и обычные фото 16:9 этим путём не обрабатываются. OCR-оценка остаётся исходной; оценка детектора не выдумывается, результат помечается как требующий проверки. Обрамление относится ко всему переданному изображению. Символы и регион не дописываются по шаблону. Выбор альтернатив и независимая сверка двух фото сохранены.

Это диагностическая выборка опубликованного датасета, использованная для исправления. Она может пересекаться с данными разработки опубликованной модели. 60/60 здесь **не означает 100% точность сервиса**, не измеряет качество на общих планах и новых уличных фотографиях. Перспектива, блики, ночь и мелкие номера требуют отдельной проверки. Нужна независимая уличная выборка, прежде чем заявлять точность продукта.

Воспроизведение:

```powershell
.venv\Scripts\python.exe scripts/evaluate_ru_dataset.py --limit 60
.venv\Scripts\python.exe scripts/evaluate_ru_dataset.py --evaluate
```

Результат: `docs/ru-dataset-evaluation.json`. Скрипт не обучается и не использует правильный ответ для исправления вывода модели.
