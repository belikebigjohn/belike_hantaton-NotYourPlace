# Иллюстрация главного экрана

Файл: `frontend/public/accessible-city.png`. Создан встроенным imagegen для этого проекта. Это декоративная иллюстрация, не фотография события и не материал для обращения.

Промпт: цельная кинематографичная иллюстрация вечерней городской улицы; доступное парковочное место с пиктограммой на покрытии; справа прямой знак «Парковка» с отдельной белой табличкой с символом коляски; автомобиль слева вне специального места; спокойные здания и деревья; тёмно-синие тени, персиковый свет и синие акценты; естественная перспектива, композиция 3:2 с безопасными полями; без людей, логотипов, номеров автомобилей, водяных знаков и рекламного текста.

Способ: встроенный imagegen, без CLI/API-ключа. Исходный результат скопирован в проект без изменения содержимого. В интерфейсе задаются пропорции и размеры, чтобы не деформировать иллюстрацию.
