# Требования и проверка

Состояние 21.11.2026. Новый стек реализован по CODEX_PROMPT_ChuzhoeMesto.md. Расширенный исходный P0 не полностью закрыт для разметки и знака под стеклом.

| Требование | Реализация | Проверка |
|---|---|---|
| Восемь экранов по референсу | React, TS, CSS Modules | Браузер, десктоп, 390 px |
| Камера и галерея | Реальный media API | Галерея пройдена; физическая камера нет |
| Номер РФ | ONNX детектор + русский OCR Nomeroff | Один upstream номер целиком; синтетический ошибочен |
| Знаки 6.4 / 8.17 | 146 классов и пространственная пара | Веса/названия и реальный запуск; независимой выборки нет |
| Разметка / знак на авто | unknown и проверка человеком | Модели отсутствуют, требование не закрыто |
| Место и время | GPS, редактирование, Photon по согласию | Форма и consent API; физический GPS не проверен |
| Черновик | IndexedDB + сервер | Перезапуск и восстановление |
| Изоляция | Cookie, owner, закрытые фото | Другая сессия получает 404 |
| Документ | DOCX/TXT/HTML и редактирование | Скачанный DOCX отрендерен и просмотрен |
| ZIP | Оригиналы, manifest SHA-256 | Реальное скачивание, побайтовая сверка и хеши |
| История | Пользовательские статусы | Экспорт и повторное открытие |
| MAX / бот | Адаптер окружения | Подключения нет |

Проверки: 28 Python-тестов, 9 frontend-тестов, ESLint, TypeScript, production build. Временная проверка моделей — один upstream-пример (возможно пересечение с обучением) и синтетическая иллюстрация. Это не независимая оценка precision/recall. Цель 60–90 секунд не измерена; задержки инструмента выбора файлов не являются временем человеческого сценария.

Следующие работы: независимая уличная выборка, модели разметки и знака на автомобиле, привязка к выбранной машине, физический телефон, условия лицензии весов, учётные записи и сроки хранения перед публичным запуском.

Дополнительно проверено: корректное различие отсутствия детекции и невозможности проверки; выбор нескольких OCR-кандидатов; качество по каждому снимку; Idempotency-Key и предварительная установка сессии; повторное подтверждение после изменения фактов.
